# OctoAcme Roles and Personas

This guide describes the responsibilities, goals, and typical communication patterns of the core OctoAcme project personas. Use it to clarify ownership and tailor project scenarios or Copilot Spaces guidance to each role.

## Personas

| Persona | Focus |
| --- | --- |
| Developers | Build, test, review, and deliver reliable software that meets acceptance criteria. |
| Product Managers | Define customer and business outcomes, prioritize work, and measure impact. |
| Project Managers | Coordinate plans, timelines, risks, dependencies, and stakeholder communication. |

## Using the guide

Refer to the full [Roles and Personas guide](../octoacme-roles-and-personas.md) for each persona's responsibilities, goals, and communication patterns. Use those details when framing project scenarios, assigning responsibilities, and creating role-specific guidance for Copilot Spaces.
